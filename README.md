# PrepFlow: Your Meal Plan

Build a mobile-first React meal prep planning app called PrepFlow. Dark theme. The main screen is a TikTok-style vertical recipe feed with recipe cards showing: a food photo, recipe name, macro bar (protein/carbs/fat), calorie count, prep time, and a macro accuracy badge (Verified / AI Estimate / Not Verified). Each card has an 'Add to Week' button. There's a weekly planner tab where you can see Monday–Sunday with meals assigned to each day, a running macro total per day, and a 'Generate Shopping List' button at the bottom. Clean, modern, fitness app aesthetic.
